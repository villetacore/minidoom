# MiniDoom — упрощённый Doom для экрана вейпа (SMOK Knight 80)

Рейкастер в стиле Doom/Wolf3D: лабиринт, 8 демонов, пистолет, здоровье, победа/смерть.
Движок рисует 128x64 монохром, на экран Knight 80 (160x80 TFT) кадр растягивается в 1.25 раза и красится в цвет. `no_std`, без аллокаций, без FPU.
RAM ≈ 1.7 КБ — влезает даже в очень слабые микроконтроллеры.

```
minidoom/
├── core/      — сам движок и игра (no_std, общий для всех платформ)
├── desktop/   — эмулятор экрана Knight 80 на ПК
└── rp2040/    — прошивка для Raspberry Pi Pico + TFT-экран Knight 80 (ST7735S 160x80)
```

## 1. Установить Rust

Windows: скачать и запустить `rustup-init.exe` с https://rustup.rs
(предложит поставить Visual Studio Build Tools — соглашайтесь).
Linux/macOS: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

## 2. Запустить на ПК (проверить, как играется)

```bash
cd minidoom
cargo run --release -p minidoom-desktop
```

| Клавиша | Действие |
|---|---|
| W / ↑, S / ↓ | вперёд / назад |
| ← / → | поворот |
| A / D | шаг вбок |
| Пробел / Ctrl | выстрел |
| V | режим «3 кнопки вейпа»: ← = «−», → = «+», обе = вперёд, пробел = огонь |
| Esc | выход |

Скриншоты без окна: `cargo run -p minidoom-core --example screenshot` (пишет `.pbm`).
Тесты: `cargo test -p minidoom-core`.

## 3. Как это устроено и почему не «прошить сам вейп»

Штатный микроконтроллер Knight 80 перепрошить своей игрой практически нельзя:
прошивка SMOK закрытая, чип защищён от чтения/записи, SDK нет, а официальная
утилита обновления по USB принимает только подписанные прошивки SMOK. К тому же
этот же чип управляет мосфетом койла — кривая прошивка может «выстрелить» 80 Вт
в испаритель или аккумулятор.

Поэтому схема такая: **игра работает на Raspberry Pi Pico (RP2040, ~350 ₽),
а от Knight 80 берутся экран и кнопки**. Плату вейпа от экрана отключаем.

## 4. Разборка Knight 80 и подключение

Нужно: Knight 80, Raspberry Pi Pico, паяльник, тонкие провода (МГТФ/ПЭЛ),
мультиметр.

1. **Вытащить аккумулятор 18650** и картридж. Дальше работать только без него.
2. Разобрать корпус (снять боковую панель с экраном, открутить винты),
   аккуратно вынуть плату — шлейф экрана тонкий.
3. Экран Knight 80 — цветной TFT 0.96" 160x80, контроллер **ST7735S**, SPI.
   Отпаять/отсоединить шлейф экрана от платы вейпа (иначе чип вейпа будет
   мешать на линиях). Контакты на шлейфе обычно подписаны или идут так:
   `GND, LEDK, LEDA, VCC, SCL, SDA, RS(DC), RES, CS` — сверьтесь с
   дорожками на плате вейпа/мультиметром.
4. Кнопки (огонь, «+», «−») — прозвонить, найти у каждой вывод, который
   замыкается на GND при нажатии, и завести на Pico. Проще подпаяться
   прямо к площадкам кнопок и общему GND.

| Экран Knight 80 | Pico |
|---|---|
| GND, LEDK (катод подсветки) | GND |
| VCC | 3V3 (пин 36) |
| LEDA (анод подсветки) | GP21 (пин 27) через резистор 10–47 Ом |
| SCL | GP18 (пин 24) — SPI0 SCK |
| SDA | GP19 (пин 25) — SPI0 MOSI |
| RS / DC | GP16 (пин 21) |
| RES | GP20 (пин 26) |
| CS | GP17 (пин 22) |

| Кнопка Knight 80 | Pico |
|---|---|
| «−» (поворот влево) | GP10 (пин 14) → GND |
| «+» (поворот вправо) | GP11 (пин 15) → GND |
| Огонь (выстрел) | GP12 (пин 16) → GND |
| Вперёд / назад (необязательно, отдельные кнопки) | GP13 / GP14 → GND |

Управление на трёх кнопках: «−»/«+» — поворот, **«−» и «+» вместе — идти вперёд**,
огонь — выстрел.

Питание: Pico от USB или от 18650 через плату-повышайку/понижайку на 5 В → VSYS
(пин 39). Напрямую 18650 на 3V3 **не подключать**.

## 5. Сборка и прошивка Pico

```bash
rustup target add thumbv6m-none-eabi
cargo install elf2uf2-rs --locked
```

1. Зажать кнопку **BOOTSEL** на Pico, подключить USB к ПК, отпустить —
   появится диск **RPI-RP2**.
2. Собрать и залить:

```bash
cd minidoom/rp2040
cargo run --release
```

`cargo run` сам соберёт прошивку и зальёт её через `elf2uf2-rs`. Вручную:
`cargo build --release`, затем
`elf2uf2-rs target/thumbv6m-none-eabi/release/minidoom-rp2040 doom.uf2`
и перетащить `doom.uf2` на диск RPI-RP2. Pico перезагрузится и запустит игру.

Для повторной прошивки — снова BOOTSEL + USB.

## 6. Если картинка не та

Все настройки — константы вверху `rp2040/src/main.rs`:

| Симптом | Что поменять |
|---|---|
| Цвета негативом (белый фон) | `INVERT = false` |
| Сдвиг, мусорная полоса по краю | `X_OFF`/`Y_OFF`: попробовать `(0, 24)` или `(26, 1)` |
| Вверх ногами / зеркально | `MADCTL`: `0xA8`, `0x28`, `0xE8` |
| Полосы, «снег» | снизить SPI с `32.MHz()` до `16.MHz()`/`8.MHz()` |
| Красный и синий перепутаны | убрать `0x08` (BGR) из `MADCTL` |
| Другой цвет картинки | `COLOR_ON` / `COLOR_OFF` |
| Экран чёрный, но подсветка горит | проверить CS/DC/RES, что шлейф отключён от чипа вейпа |
